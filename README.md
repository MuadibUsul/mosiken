# mosiken.org

The company website for [Mosiken](https://mosiken.org), an independent software company registered in Wyoming, USA.

It is a static site in English and Simplified Chinese: plain HTML, one stylesheet, three small JavaScript modules, no runtime dependencies. The HTML is generated by a small script and committed, so any static host can serve the repository root as-is, with no build step.

## Pages

| File | Purpose |
|---|---|
| `index.html` | Home: hero, introduction, product index, mission, contact |
| `products.html` | Veynod, ANCS, Serendipity and SheetOS, each with its current stage |
| `about.html` | Company profile, mission, vision, how we build, facts |
| `contact.html` | Email address, corporate details, and contact topics |
| `privacy.html` | Privacy Policy for Mosiken LLC websites and software |
| `terms.html` | Terms of Service for Mosiken LLC websites and software |
| `404.html` | Not-found page (uses root-absolute paths so it works at any depth) |
| `zh/…` | The same seven pages in Simplified Chinese |

## Languages

English pages live at `/` and Simplified Chinese pages live at `/zh/`, linked via an explicit language switch in the navigation and footer (without automatic client-side redirects, ensuring deterministic inspection for users, search engines, and compliance reviewers). Every page lists its counterpart with `hreflang`, and `sitemap.xml` carries the pairs.

Both versions consistently represent the single legal entity **Mosiken LLC** (registered in Wyoming, USA; Chinese brand name `衍川`), founded and wholly owned by Chen Su. The clock runs on Mountain Time (`America/Denver`), the registration state's time zone.

## Structure

```
assets/
  css/main.css     design tokens, layout, components, light and dark themes
  js/main.js       theme toggle, menu, clock, reveals, product index, footer wordmark
  js/field.js      the WebGL chart that runs behind every page
  js/scenes.js     the four animated product scenes (2D canvas)
  fonts/           Archivo, Chivo Mono, and a Chinese subset of Noto Sans SC, with their licenses
  img/             icons and the social preview images (og.png, og-zh.png)
tools/
  copy/en.mjs      every English string on the site
  copy/zh.mjs      every Chinese string on the site
  build-pages.mjs  writes the HTML for both languages and sitemap.xml
  subset-font.py   cuts the Chinese font down to the characters in use
favicon.svg, favicon.ico, site.webmanifest, robots.txt, sitemap.xml
```

## Changing copy or page structure

Edit `tools/copy/en.mjs` and `tools/copy/zh.mjs` (and `tools/build-pages.mjs` for structure), then regenerate and commit the result:

```bash
node tools/build-pages.mjs
```

Do not edit the generated `.html` files by hand; the next build overwrites them.

The product scenes draw their own labels; those strings live in the `WORDS` table at the top of `assets/js/scenes.js`.

If the Chinese text gains characters, re-cut the font so they render in the site's typeface rather than the reader's system font (characters outside the subset still show, just in a different face). The source font is [Noto Sans SC](https://github.com/google/fonts/tree/main/ofl/notosanssc):

```bash
pip install fonttools brotli
python3 tools/subset-font.py path/to/NotoSansSC[wght].ttf
```

## Preview locally

ES modules do not load from `file://`, so use any static server:

```bash
python3 -m http.server 4173
```

Then open <http://127.0.0.1:4173>.

## Editing

- **Copy** lives directly in the HTML files. Product status wording is deliberate: keep "available", "in development" and "research" accurate for each product.
- **Colors and type** are tokens at the top of `assets/css/main.css`. The two dark blocks redefine the same tokens; change both together.
- **The chart** (`assets/js/field.js`) draws on the one `canvas[data-field]` at the top of each page. `data-gyre` on that canvas gives the page a whirlpool, `data-field-stage` marks the section where the chart is loud and answers the pointer, and `data-zone` marks a section that sits on a tinted band.
- **Product scenes** live in `assets/js/scenes.js`. An element with `data-scene="<id>"` plays the matching scene; `data-beats="#list"` links an ordered list whose items light up as the scene moves through its steps. Each scene shows the idea behind a product, not its interface: keep them honest about what is shipped.
- **Social preview** is `assets/img/og.png` (1200 × 630). Replace it if the headline changes.
- **Sitemap**: update `lastmod` in `sitemap.xml` when a page changes, and add new pages there.

Motion respects `prefers-reduced-motion`, and every page reads and navigates with JavaScript turned off.

## Deploying

Serve the repository root at `https://mosiken.org/`. Links between pages are relative and keep their `.html` extension, so no rewrite rules are needed. Point the host's not-found handler at `404.html` (GitHub Pages does this automatically).

A minimal Caddy site block, as a starting point:

```
mosiken.org {
	root * /srv/mosiken
	encode zstd gzip
	file_server
	handle_errors {
		rewrite * /404.html
		file_server
	}
}
```

Asset file names are not fingerprinted, so avoid long-lived `immutable` caching for `/assets/`.

## Details worth keeping

A few things on the site are intentional and easy to mistake for leftovers: the coordinates beside the gyre in the hero, the paper boat, what happens when the water or the footer wordmark is clicked, the 404 headline, and the comment at the top of each HTML file. Please leave them in place.
